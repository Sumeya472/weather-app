# Frontend Mentor - Weather app

![Design preview for the Weather app coding challenge](./preview.jpg)

A responsive weather app built with **HTML, Tailwind CSS, and JavaScript** using the **Open-Meteo API**.

## ✨ Features

- 🔍 Search any location
- 🌡️ Current temperature & weather conditions
- 💧 Humidity, wind & precipitation
- 📅 7-day forecast
- 🕐 Hourly forecast
- ⚙️ Celsius/Fahrenheit, km/h/mph, mm/in
- 💾 Saves the last searched location with `localStorage`
- 📱 Responsive design

## 🛠️ Technologies

- HTML
- Tailwind CSS
- JavaScript
- Open-Meteo API
- LocalStorage

## 🚀 How It Works

Search a city → get its coordinates → fetch fresh weather data → display it.

The last searched city is saved in `localStorage`, so after refreshing, the app automatically loads that location again.
